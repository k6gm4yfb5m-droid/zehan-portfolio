# Li Zehan · Design Portfolio

Static HTML portfolio featuring visual design, brand and campaign concepts, information design and independent AIGC work.

## GitHub Pages

Publish the `main` branch from `/ (root)` in **Settings → Pages → Build and deployment → Deploy from a branch**.

- Entry: `index.html`
- No build command or dependency installation is required.
- `.nojekyll` serves the authored static files directly.
- Keep `assets/`, the stylesheets and JavaScript alongside all nine HTML pages.

## Preview locally

```sh
python3 -m http.server 8080
```

Open http://localhost:8080/.

## Content

Profile plus eight case studies: virtual water / Chatham House × Soapbox, ONE KIDNEY CAN / GOOD Agency, Lisbon Maru memorial, Islander / Beyond Words Studio, Design for Istanbul, EMBERS / Ember, Memory Mapping, and kami coffee.

Academic industry briefs, team contributions and fictional AIGC brand concepts are identified on their respective pages. Company internship work is described in text.
