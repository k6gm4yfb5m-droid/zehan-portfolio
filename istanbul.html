01 / THE DESIGN CHALLENGE

用一套图形语言，建立城市的视觉记忆

从一次伊斯坦布尔旅行出发，我将建筑、装饰纹样与个人城市印象转化为视觉线索，探索一套面向未曾到访者的文化传播设计。

设计重点是让文化元素形成可识别、可组合、可延展的表达。我通过符号提炼、统一配色与模块化编排建立图形系统，再延展到海报、图案和文创应用，让同一套城市印象贯穿不同载体。

DESIGN VALUE

从文化概念，走向可复用的视觉资产

项目将视觉识别思维与传播应用结合：把城市印象提炼成图形元素，通过配色、轮廓与构图形成系列一致性，并在传播画面与日常物件之间延展同一套视觉语言。

02 / DESIGN DECISIONS

四个设计决策，连接文化、图形与应用

01

提炼城市线索

从旅行记忆中的建筑轮廓、装饰纹样与城市细节出发，以概括的几何形态组织视觉元素，强调可辨认的轮廓与节奏，为后续组合留下空间。

SYMBOLS
02

建立统一的视觉语法

用蓝、黄、绿、粉的高对比配色连接不同元素；通过黑色轮廓、方形模块、重复与对称建立画面规则，让图案与海报在变化中保持同一套视觉性格。

SYSTEM
03

拓展平面与立体表达

系列海报分别呈现符号矩阵、建筑体块与立体构成，以不同的图形密度和空间关系展开同一主题；统一的标题与装饰元素维系系列识别。

SERIES
04

让视觉适应不同载体

海报集中呈现城市主题，帆布袋通过横向组合和标题建立完整画面，钥匙扣则聚焦单个图形。通过组合与简化，让同一套视觉资产适配传播与文创场景。

APPLICATION
03 / VISUAL SYSTEM IN USE

从系列海报，到日常物件的视觉延展
